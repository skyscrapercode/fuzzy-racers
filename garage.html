Fuzzy Logic Documentation

ISP568 · Fuzzy Racers

Overview

The AI opponent in Fuzzy Racers is driven by a Mamdani-style fuzzy inference engine (js/fuzzy.js). On each tick the engine takes six crisp race telemetry values, fuzzifies them into degrees of membership across named linguistic sets, evaluates 33 rules in parallel, aggregates their outputs, and defuzzifies by centroid to produce throttle, brake, steering, aggression, and use-powerup commands.

The sections below are generated live from FuzzyEngine.getVariableSchema() and FuzzyEngine.getRules(), so they always match the engine that ships in this build.

Input Variables & Membership Functions

Each input is a linguistic variable: a numeric universe carved into overlapping fuzzy sets. A given input value belongs to each set with some degree in [0,1] — that's the y-axis of the charts below.

Output Variables & Membership Functions

The engine produces five outputs. For each output, multiple sets can be "activated" by different firing rules; the activation strengths are aggregated by max() and the resulting clipped membership curve is then defuzzified.

Rule Base (33 rules)

Rules use min() for AND. Multiple rules can target the same output; their activations are aggregated by max().

Defuzzification — Centroid Method

For each output variable, the engine samples the universe at 101 evenly-spaced points. At each sample point, the aggregated output membership is the max() across all activated sets — each clipped at its firing strength (Mamdani inference).

The crisp output is then the centroid (center of gravity) of that aggregated curve:

crisp = Σ(x · μ(x)) / Σ(μ(x))

This is what becomes the AI's throttle (0–100), brake (0–100), steering (-100…+100), aggression (0–100), and use_powerup (0–100). For use_powerup, anything above 70 makes the controller actually fire the held powerup.
